# 中文界面字体

游戏 UI 使用 **Noto Sans SC Regular**（思源黑体体系的简体中文版本），字体随资产目录发行，无需玩家安装系统字体。所有 UI 文本显式绑定同一个字体句柄；截图模式等待字体加载完成。

- 官方仓库：[notofonts/noto-cjk](https://github.com/notofonts/noto-cjk)
- 固定版本：`f8d157532fbfaeda587e826d4cd5b21a49186f7c`
- 原文件：[Sans/SubsetOTF/SC/NotoSansSC-Regular.otf](https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf)
- 文件大小：8,331,336 字节；未修改、未自行子集化。
- SHA256：`faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`
- 许可：SIL Open Font License 1.1，原文保存在同目录 `OFL.txt`；版权信息保留在原字体元数据内。打包时须同时保留字体和许可，不可把字体单独出售。

这是第三方开源字体，不是本项目原创美术。正式 UI 图标、面板美术与多语言切换仍属于后续工作；目前只提供中文界面，不引入多语言框架。
