# M1 · 建筑工具推进

2026-10-09。本轮遵循既有 Windows 桌面计划的 D2/D3，不增加万级世界、分区流式加载或 LOD 任务；仅本地修改，未提交/推送。

## 已接入的可用功能

| 操作 | 语义与反馈 |
|---|---|
| 点击/切换体块 | 从实际展示网格的 PartId 取得 BlockId；按钮轮换体块；状态显示编号、层数、高度 |
| 宽深控制点 | 橙点只改宽、蓝点只改深；普通尺寸拖动同时改宽深；使用建筑局部轴，不拉伸门窗 |
| 高度控制点 | 绿色控制点与高度工具使用固定的竖直手势平面；根据起点计算绝对米数，不累计像素误差 |
| 旋转控制点 | 紫点/圆环旋转整栋；底层中心固定，跨 +/-π 连续展开，再将目标角规范化；不改变建筑内承托 |
| 添加上层 | 在当前体块上生成居中、约 70% 宽深的一层体块；继承屋顶/立面；校验最大 3 体块、4 层支撑链与承托边距 |
| 移动/删除上层 | 移动上层及其后代、保持相对布局；越界整体拒绝；删除上层连同后代；不把底层操作伪装成上层操作 |
| 屋顶/立面/增高降低 | 修改当前体块；立面轮换现有石、灰泥、木材；删除房屋仍删除整个聚合 |
| 候选预览 | 固定 6 个实体、3 个共享网格、2 个材料；半透明墙体和简化屋顶随候选即时更新，正式门窗保留原样 |

拖动不修改权威数据、历史或生成队列；松开一次 CommitPreview，取消/无效终点不提交上一次有效位置。移入 UI 后松开、右键、失焦等继续使用已有 PointerRouter 的取消语义。控制点使用 16 个逻辑像素的拾取半径，单独覆盖层绘制，不因挡在屋后就不可见。

候选池只更新实际改变的 Transform/Mesh/Material/Visibility，稳定预览不反复触发渲染组件变更；网格只在 Startup 创建。提交后 PendingTargets 接续简化实体预览，直到正式版本完成交接。预览实体没有 DisplayedBuilding，不参与三角形拾取、历史、存档或后台生成。四坡预览是简化四坡体，不包含正式屋脊、开孔和贴图。

所有新工具复用原来的取消、票据、局部缓存、分帧上传、资源就绪和过渡链路。显示票据过期时拒绝开始新的控制点编辑；正式三角形拾取和控制点都使用当前显示姿态，不拿尚未展示的目标几何替代。

## 抽象与落点

- domain：TranslateBlock 以绝对局部位置移动支撑子树，SetFacade 修改语义立面；整个聚合重新验证，失败不产生部分修改。
- application：next_block_id 包含历史墓碑，普通添加不复用撤销/删除过的编号；ToolController 保存体块选择和临时事务，ResizeAxes 区分宽/深。
- presentation/controls.rs：从显示布局导出控制点，逻辑像素命中、固定手势平面和覆盖层；不修改领域。
- presentation/editor.rs：指针/中文按钮转换为公开工具用例，反馈修复失效选择。
- presentation/preview.rs：常量规模的展示资源池；不复制权威世界，不编译详细网格。

仍为六个 crate，四个纯核心不依赖 Bevy；没有为了按钮新建插件框架、通用事件总线或空存储接口。

本轮最终全量测试、Clippy、格式与模块边界结果记录在[验证记录](验证记录.md)的 M1 小节。自动回归覆盖绝对高度、旋转中心与角度边界、独立宽深、子树移动/删除、编号不复用、承托失败、撤销、控制点优先拾取、过期显示拒绝，以及稳定预览不反复标脏。

两幅图已目视检查中文、控制点、上层与预览。工具集成脚本首次因阶段间选择被清理而失败，已显式重建合法选择并重跑通过；不是玩家鼠标操作的记录。预览检查首次发生 Intel UHD 630 / 驱动 31.0.101.2141 的 DeviceLost/Out of memory；消除稳定预览的重复组件更新后重跑退出 0，但未独立证明设备丢失根因，不能据此宣称所有驱动稳定。
