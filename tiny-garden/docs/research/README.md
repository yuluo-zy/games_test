本次采用静态解析。`.texture` 的像素内容、FMOD 音频事件、二进制场景快照和光栅着色器第二阶段尚未解码。模型三角形候选按三角列表索引数除以三统计，不能直接当作运行场景复杂度；包围盒使用模型局部坐标，未确认其单位。

导出后已逐行核对全部文件、模型、着色器与引用记录，检查数量、总字节数、汇总缓存值、筛选表和冻结窗格，并检查所有工作表的排版。资源清单用于研究参考，与 Tiny Garden 自制运行时资产清单分别维护。
