# 上下文系统实现与验收

2026-10-10。当前桌面实现与[架构设计](上下文自动重构系统架构.md)对应；本页记录实际数据合同、操作和性能边界。既有墙路文档保留第一阶段历史。

## 数据与唯一规则入口

六个 crate 的依赖方向保持不变。应用层不依赖生成层；上下文意图和最小迟滞决策属于领域，关系与结构属于纯生成，Mesh/Entity/材质属于外层。没有属性字典、规则 DSL 或反射求解器。

| 数据/文件 | 语义 |
|---|---|
| domain/context.rs | SceneContext、LinearIntent、OpeningIntent、FoundationIntent、墙面锚点和最小 DecisionState |
| domain/terrain.rs | 稀疏 Arc 高度块；0.25 米单元、4 米块、共享边界顶点 |
| application/context.rs | 隔离候选、原子提交、变更集、对象/空间桶读集、历史和编号墓碑 |
| generation/context.rs | 类型 → 路网/边界连接 → 地基/穿越 → 最终立面；预览和正式提交调用同一解析入口 |
| generation/context_cache.rs | 路网、根轮廓地基及各墙面的精确语义缓存 |
| generation/context_mesh.rs | 地形/路面分块、篱笆、转角、组合框和地基；复用既有几何基础 |
| bevy-adapter/context.rs、slots.rs | 后台语义事务、共享池槽位、跨类型发布就绪及共同起点 |
| bevy-adapter/stroke_context.rs | 派生几何组的精确缓存，来源键与显示编号隔离 |
| presentation/context_tools.rs、handoff.rs | 桌面手势、独立候选、统一显示交接状态；上传仍复用 upload.rs |

关键状态转换、缓存失效、单位和选择理由在对应模块及接口附近使用中文注释说明。

## 桌面操作

工具栏按“房屋参数”“墙路参数”“地形与窗”展开；编辑按钮继续经同一命令入口。普通画墙/画路是显式锁定类型；自动画笔先生成道路，选中后以 0.1 米步长调高可变为篱笆、围墙，原 StrokeId 与控制点来源保留。可恢复自动推断、锁定三种类型、切换木/石样式倾向。

地形工具支持抬高、降低和平滑，半径 1.5 米，强度 0.6 米/秒。整次笔刷候选独立，收笔一次提交；取消不改变意图、依赖索引或历史。地面射线通过 DDA 测试实际单元三角形，显示和高度查询使用同一对角线。

“放置窗”在实际可见墙面创建手工窗；“编辑窗”选中后拖动位置，可加宽、收窄或删除。窗户锚定 BuildingId、BlockId、语义墙面和沿墙参数，休眠时保留编号及原位置。重复点击“编辑窗”可轮流选中原始手工窗，包括休眠窗，仍可调整宽度或删除。墙面拾取会检测其他结构及地形遮挡，建筑显示姿态尚在移动时暂不接受新窗。

## 关系约束及恢复

- 类型：道路进入/退出高度 0.08/0.18 米；围墙进入/退出 1.5/1.3 米。木/石样式调整围墙倾向，宽度超过 0.8 米偏向实墙；显式锁定优先。
- 道路：端点、T 字口、中段交叉和共线重叠保留原笔画及区间来源；高度容差 0.1 米，连接进入/退出距离 0.15/0.25 米；坡度超过 35° 标记不可通行，拒绝自动门。
- 篱笆/围墙端点：高度、材料和方向兼容后建立连接；共用端柱/转角构件由稳定来源成员确定所有者。
- 连窗：同宿主、同样式，垂直差不超过 0.08 米；间距进入/退出 0.18/0.28 米；最多 4 窗，总跨度最多 5 米。仍按每个有效窗洞开孔，公共上下框连接组合，不以大包围盒挖洞。
- 自动门：实际穿越墙面且夹角、宽度、承托边距与地面高度合法才生效。自动门优先，冲突手工窗休眠；道路移开/删除后恢复。自动窗避让有效覆盖。
- 地基：旋转根轮廓与地面三角形精确裁剪，取最高标高；建筑保持水平。FoundationIntent 以最低绝对标高和净空表达承托策略，不改写玩家 Placement。未编辑地形的旧场景保留原标高。

已提交类型、端点连接选择和连窗成员进入同一撤销事务。撤销/重做恢复原历史栈，再后台解析关系；不会为自动附件新增历史。宿主消失的手工窗休眠，撤销恢复宿主后重新解释。

## 异步、增量和资源生命周期

候选捕获会话、单调版本及空间读集，包含空桶依赖；任一提交条件过期则拒绝整个事务。正式语义任务串行接受，保留玩家操作顺序。预览只保留一项在途与最新待解析快照；持续拖动可显示同手势已完成的候选，收笔等待最新候选解析后才提交，取消后的旧结果不发布。场景替换把旧任务移到待回收列表，实际完成前仍占用池槽位。

所有语义、建筑、线性网格和预览任务共享有界池槽位。地形、路面按 4 米分块，地基按根轮廓/姿态/局部地形缓存，组合按稳定成员来源缓存；无关网格沿用同一 Arc 和 GPU 句柄。显示编号由强类型来源注册表分配，避免拼接对象位数造成编号碰撞。自动门显示槽位跟随道路区间来源，删除其他门不会改变存续门的身份。平坦地面与编辑后地形始终使用同一分块表示，避免首次笔刷及撤销时切换两套地面。

上传期间保留旧完整展示，冷材质预热确认前不切换。初始化必须等真实生成结果就绪，修订号 0 的默认值不代表空场景已经生成。受影响建筑及线性组全部就绪后共享起点；160 毫秒交接在中点切换拾取，结束清理旧网格、临时材质和预热实体。已经开始的交接完成后再接最新目标；未开始的过期暂存直接回收。

当前单场景最多 32 笔，每笔 128 点/60 米，手工窗最多 256 个，地形高度 -1.5 至 3 米。根事务仍采用全局版本的保守校验，路网拓扑是有空间候选筛选的有界整体解析，任一道路变化可使路网语义缓存失效；局部网格仍精确复用。没有把这套原型宣称为万级流式世界或每个路口独立调度。

## 当前表现边界

道路边缘保留 0.25 米栅格量化，急折角、自交墙咬合仍需专项几何优化；地形不支持悬洞或多层地表。建筑自动门现在复用既有矩形洞及门框资产，连窗保留独立窗扇与公共上下框；没有新增全套门窗美术。窗户样式是兼容性参数，尚无丰富的样式选择器。

地形/手工窗候选采用低细节线框，建筑候选使用固定池形状；语义规则与正式生成相同，但候选不是完整贴图网格。未增加导航代理、物理行走、存档、移动端或触摸适配。
