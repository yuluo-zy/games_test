# 房屋资产首批制作简报

2026-10-09，目标为可编辑桌面建筑，而非复刻 Tiny Glade 的模型或商用素材。

## 制作约束

- 平台：桌面 Bevy；保留尺寸、层数、三种屋顶及退台的程序化结构。
- 造型：温暖灰泥、柔和石砌、低饱和蓝灰屋瓦、厚木框与深色窗内；大形体先于细节。
- 第一批：window-basic（500 三角形/2 材质）、window-shutter（800/2）、door-timber（500/2）、chimney-stone（500/1）。不代表 26 个规划资产全部完成。
- 四套重复材质：1024² sRGB BC，512² OpenGL 线性 N，512² 线性 ORM（R=1，G=粗糙度，B=0）。不将 AO 烘进 BC。
- 1 单位=1 米，Blender Z 向上、-Y 朝外，导出 +Y 向上、+Z 朝外；窗枢轴为洞口底部中心，门为地面底部中心，烟囱为底部中心。
- 窗适配使用明确的裁切/伸长分区：边框厚度保持，中心与直段适配洞口；不是整体缩放模型。门宽不足时不放置，烟囱只放在足够大的顶层屋面。
- UV 是米制重复投影，故意重叠以共享瓦片，不是唯一烘焙图集；不使用静态光照，暂不需要第二光照 UV。
- 静态附件无骨骼动画。保留 LOD 源，但首版先验收近景模块；远景 LOD 自动切换后续实现。
- 无行走/物理系统，沿用建筑 CPU 网格进行编辑拾取，不引入碰撞引擎。

## 流程与接口

使用 blender-director、environment-artist、stylized-style、cozy-wholesome-mood、materials、uv-workflow、texture-workflow、asset-optimization、export-pipeline、qa-review。

没有 Blender MCP 接口，使用已有 Blender 后台 bpy 执行。源场景保留参考、模块、LOD、灯光与相机集合；不修改用户正在打开的场景。不覆盖已有资产：新版本写入新的输出目录。

Blender → 同一份三角化网格导出 GLB 和紧凑运行时 kit.json → Rust 验证 → 每栋房屋五个材质合批 → Bevy 实际截图验收。GLB 是 DCC 交换件，运行时不重复解析 GLB：加载其同源编译产物；资产路径、贴图与句柄只在表现层，领域层无变更。

门是外立面装饰模型，首版不进入建筑；以首层正面一个窗口槽替换成完整门洞，不能把门简单贴在完整墙上。布局需保持相同规则用于墙洞、附件与拾取。

## 验收

导出前检查尺度、单位变换、三角形、材质、闭合组件、法线、UV 和命名；Rust 再验网格及 GLB 预算。查看 Blender 预览和引擎全景/近景，测试三种屋顶、小尺寸、多层、退台及编辑重建。未完成移动端、远景 LOD 与全量资产清单验收时，不能宣布整个美术批次 production approved。
