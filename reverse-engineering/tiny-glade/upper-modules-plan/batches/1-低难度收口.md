# 批次 1：低难度 + 已部分恢复的先收口

**目标**：把体量小、已有部分实现/证据的模块先闭合，产出可复用的验收模板，并解锁批次 2/3。

**模块**：water、tree-tool、forest、timberframe、glade-border、roof（剩余族）

**顺序**（建议）：water → glade-border → timberframe → forest → tree-tool → roof

**为什么先做**：
- 体量小（合计 26 文件 / 48 业务函数），单模块可在一次会话内闭合。
- roof 的 CPU 铺瓦核心已完成，只剩视觉/音频/触发体等尾巴，收口成本低。
- water / tree / clutter 已在 core 侧有部分 CPU 实现，可直接复用。

**并行性**：6 个模块互不依赖，也可全部并行；每个 agent 用唯一 worker。
