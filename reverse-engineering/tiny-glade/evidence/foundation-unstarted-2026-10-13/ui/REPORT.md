# B UI business recovery

Four crates follow the original B directory boundaries. Public iced/winit platform/widget implementations are excluded. The source is a compiled candidate business interface; it is not the author's original source or verified Rust ABI.

Observed functions and each rule are mapped in manifest.json. RNE instruction execution covers 150 dialog leaf entries and 92 GPU/workaround message leaf entries. Neither record claims full GUI validation.

MCP identity: B patched SHA cf048e27acdc266b2efc7c094dd435bacecb3f26c2afe54de4d09cd3f7036323. Oracle: B RNE SHA f507a6cea25c5199447b88ba746a5293e64a279f73797ca74c1ce7f4ff2b7d03. All range hashes are checked against the worker before bounded preparation. Jump table overlays derive from original RNE table bytes and persist only in ui-unstarted-20261013, not the original seed.

The unchanged public dependency driver classification at rhapsody::raw::init::AvailableGraphicsDevice::driver_support supplies UI advice. GPU selection preserves the provided device indices; it does not fabricate or initialize a GPU. The report callback is supplied by a consumer; no report is sent by this task. Clipboard and file operations are adapter boundaries.

Known limitations are explicit in manifest.json. Root Cargo.lock and dependency acquisition are integration-owner responsibilities. No C paths or C behavior were imported.

Native backend now uses the exact original B forks: iced 2bccf7317e42422cb3b98c0de4f291d8c0865380, winit d03de0a0a881be9422c360083151b0e7a8a2582e, cosmic-text 3da2a14ea3d063875fdc55695431e74405302b0f. Application/window/widget/tiny-skia rendering and subscriptions are reused rather than reconstructed. Game controls supply owned widget trees and native platform adapters for browser, path, clipboard and scoped file removal.

Default native-gui --offline --locked --all-targets Cargo check, 11 CPU tests and strict Clippy passed. Final affected check/Clippy/example link gate passed after font shaping glue. Five actual native windows were captured and exited automatically; latest PNGs were inspected by this agent and the integration owner. Raw RGBA, dimensions, SHA-256 and process exits are recorded in native-captures.json and native-processes.json. Earlier hidden/all-background and Basic-shaping/missing-emoji captures are retained as rejected attempts and do not count toward final validation. Advanced shaping preserves original strings/icons and activates public cosmic-text system font fallback. Source-level native layout and tick cadence remain candidate integration choices, not original GUI pixel/ABI equivalence. No platform IO action is triggered by the presentation probes.
