### 1. `ComputePass::new<S>`（0x1405876a0 系 14 实例，400B 返回）—— 声明链
处理链（O，B_a4_compute §2）：
1. `calculate_hash((src, &()))`（SipHash-1-3 零密钥）→ 着色器源缓存键；
2. `get_compute_by_name`：命中 → `clone()` 复用既有 `ComputeShaderProgram`（着色器只编译一次）；
   未命中 → `as_compute_pipeline()`（带 `PERM_*` defines 的实例 2311B 与不带 1943B 两形态）→
   `ComputeShaderProgram::new` → `add_compute` 入缓存；
3. 取 `GraphicsDeviceResource`（缺失 → `Option::unwrap`）；
4. `UniformBinder::new`（见 uniform_binder 章）；
5. `bind_color_library`（0x1405896e0/0x1415fc070：无槽表、access 0x1a、槽哈希 `0x52ec6a17beb8fef0` = fnv1a("ColorLibrary")）。
- 数据结构：400B = `bindings Vec<RenderPassBinding(0x44)>@0` + `access_ranges Vec<8B>@0x18` + `external_bindings Vec<0x48B>@0x30` + `PassBuilder@0x60` + `UniformBinder@0x110/0x120/0x136`（+0x136==8 = 无 uniform 块 niche）+ 着色器反射 hashbrown@0x138（键=绑定名哈希 u64，值=(SetIndex,BindingIndex)）+ 设备@0x140 + `PassResources(56B)@0x148`。方法**按值消费 self**（编译器 memcpy 0x190 回传）。

### 2. SSBO 访问族（read/write/_concurrent/write_to_cpu_mapped）—— 记录链
- `read_rg_storage_buffer(hash)`（0x14096dac0）：注册表查 `{set,resource}` → **未命中整体静默跳过**；命中 → `assert_eq!(set,0)`（反射 set 必须为 0）→ `add_resource_access(resource, 0x1a, 组1)` → **绑定数≥0x100 → unwrap 失败 panic（在 add_resource_access 之后，访问已登记）** → 追加 0x44B `RenderPassBinding`（读标签 3 / 写标签 4）→ access_range。
- `write_rg_storage_buffer`（0x14096dd60）：同 read，访问码 **0x37**、组 0。`write_rg_storage_buffer_concurrent`（0x14096e000）：同 write，**同步组=调用方参数**（9 实例，如 NaniDrawListSsbo 0x141608450 访问码 0x37 实测）。
- `read_storage_buffer<T>`（0x14160c290 系 25 实例）：`read_access_buffer<T>(access 0x1a)` —— **完全不经注册表**，`get_rg_buffer<T>` 资源号 = `handle+0x10` → add_resource_access → 绑定数检查 → 追加（读标签 3），**返回追加前下标**；再查注册表按 hash 追加 access_range（仅 `write_to_cpu_mapped` 3 实例 0x141609770 系做这步）。
- `write_storage_buffer<T>`（0x1416044c0 系 34 实例）：`write_access_buffer<T>(access 0x32)`、组 0。
- **访问码表**（O）：compute 读 SSBO 0x1a / 写 0x37 / `*_storage_buffer` 与 cpu-mapped 写 0x32 / 间接参数读 0x02 / 传输写 0x34 / DrawBuilder 读 0x1f；`is_write = (a-0x28)<0x10`（0x140c10e10）。

### 3. `bind_texture_to_compute_pass<A>`（0x140905260 系 8 实例）—— 双路径
- RG 路径：注册表未命中 → **只写维度 uniform**（键 `fnv1a(name)+1`，值 `[w,h]`，闭包惰性求）；命中 → assert set==0 → 绑定数检查 → `add_resource_access(res, access, write?0:1)` → `Ref::bind_view`（整块 0x3cB `TextureViewDesc` 进绑定，+0x3c 资源号、+0x40 写标志）→ AccessRange → 维度 uniform。
- 外部路径（标签 1 受管 / 2 FromDisk）：`assert!(!access.is_write())`（0x24B 文案）→ 视图必须 None 否则 `panic!("TODO?")`（0x142aaa7c8）→ 追加 0x48B 外部记录 `{binding@0, 判别0@8, sampler 0@0x10, image_view@0x18, layout 5@0x20, 句柄克隆@0x28, 标志 0@0x40}` → 维度 uniform；**不登记 RG 访问、不追加 AccessRange**。
- 只读类型（`TextureFromDisk`/`&Handle`/`&ReadOnlyHandle`）在注册表查找**之前**检查：`is_write(access)` → `panic!("Trying to bind {:?} for writing, but it's not writable")`（0x142aaa898）。

### 4. `bind_external_storage_buffer` / `bind_external_raw`（0x14096e2a0 / 0x14096e540）
- external buffer：assert set → `GraphicsDevice::get_vk_buffer`（None → unwrap）→ 0x48B 记录 `{binding, tag 5, vk, 0, u64::MAX(-1), 句柄克隆, 0}` 插入。
- raw：复制调用方 **8×u64 原始描述符** 到 0x48B 外部记录（命中覆写绑定号；未命中丢弃）。

### 5. dispatch 家族（模式 0..4，`dispatch_impl` 0x14169af70 渲染回调）
| 方法 | 地址 | 模式 | 行为 |
|---|---|---|---|
| `dispatch_groups` | 0x14096ee10 | 0 | render-top/decomp/decomp-0x14096ee10.txt（原 线程组数（x,y,z），无间接、无闭包） |
| `dispatch_1d` / `dispatch_2d` | 0x14096eaf0 / 0x14096ec80 | 1 | render-top/decomp/decomp-0x14096eaf0.txt（原 线程总数（缺省维=1）；1D 组数=count、2D 双维） |
| `dispatch_indirect_raw` | 0x14096e880 | 2 | render-top/decomp/decomp-0x14096e880.txt（原 `add_resource_access(buf, 0x02, 组1)` 后经间接缓冲） |
| `dispatch_with<F>` | 0x14160a2e0 系 9 实例 | 3 | render-top/decomp/decomp-0x14160a2e0.txt（原 闭包 400B env **装箱** + 函数指针入记录） |
| `dispatch_indirect_with<F>` | 0x14160b850 系 6 实例 | 4 | render-top/decomp/decomp-0x14160b850.txt（原 模式 3 + 从 args+0x10 读 indirect resource_index + add_resource_access） |
- 回调体（0x14169af70）：push constants → 按模式分派。组模式：`[dev+0xaba]==1` → 先 `issue_full_pipeline_barrier`，锁内计数+1，`vkCmdDispatch`（device+0x360）；间接模式：`ResourceRegistry::buffer`（缺 → "Resource does not exist" panic）+ `vkCmdDispatchIndirect`；闭包模式把 `ComputeDispatchApi` 交给闭包。
- `ComputeDispatchApi::dispatch_3d`（0x14096efa0 立即模式）：**local size 三项为 0 → div_by_zero（先于屏障）**；屏障；`ceil` 除法（`(count+size-1)/size`）；锁内计数+1；`vkCmdDispatch(cmd,gx,gy,gz)`。
- 模式→Rust 枚举名 U（DrawMode 保留 u32）。

### 6. panic/断言 汇总
绑定数 ≥0x100 unwrap（在 add_resource_access 后）；local size 0 div_by_zero（先于屏障）；注册表未命中**静默**；设备缺失 unwrap；`assert_eq!(set,0)`；`bind_external` vk 缓冲缺失 unwrap；着色器缺失 unwrap。

## 证据注记（tg_rn1）
- **ComputePass 400B 布局**（O）：+0x00 bindings Vec<RenderPassBinding(0x44)>、+0x18 access_ranges Vec<8B>、+0x30 external_bindings Vec<0x48B>、+0x60 PassBuilder、+0x110/+0x120/+0x136 UniformBinder（+0x136==8 = 无 uniform 块）、+0x138 &着色器反射（hashbrown：键=绑定名哈希 u64，值=(SetIndex,BindingIndex)）、+0x140 &GraphicsDevice、+0x148 PassResources(56B)。方法按值消费 self（memcpy 0x190 回传）。
- **访问码**（O）：compute 读 SSBO 0x1a；写 0x37；`write_*_storage_buffer`/cpu-mapped 0x32；间接参数读 0x02；传输写 0x34；`is_write = (a-0x28)<0x10`（0x140c10e10）。同步组：读 1 / 写 0 / 并发写=调用方。
- **注册表语义**（O）：每次命中 `assert_eq!(set, 0)`；AccessRange.resource_index 存的是 **BindingIndex** 不是资源号；`*_access_buffer<T>` 完全不经注册表。
- **dispatch 模式**（O）：0 组数 / 1 线程总数 / 2 间接 / 3 闭包 / 4 间接+闭包；渲染回调体 0x14169af70（组模式 device+0xaba==1 → 屏障+计数+1+`vkCmdDispatch`；间接模式 "Resource does not exist" + `vkCmdDispatchIndirect`）。模式→Rust 枚举名 U（DrawMode 保留 u32）。
- **panic/断言**：绑定数 ≥0x100 `unwrap_failed`（在 add_resource_access 之后）；local size 0 `div_by_zero`（**先于屏障**）；注册表未命中静默跳过。
- U：`bind_texture` 受管/`TextureFromDisk` 外部绑定路径（标签 1/2 的记录布局 O 于 B_i_api §3.2，本文件只实现了 RG 路径）；`ComputePass+0x140` 确切类型（I：设备）；push constants 原始承载字段（I：自行保存字节）；`write_storage_buffer_concurrent` 原版实例 = 9 个（NaniDrawListSsbo 0x141608450 等）。
