## 3. 针对性问题清单

### 3.1 FIX——EventReader 消费语义
机器码每次把游标推进到双缓冲末尾（`*puVar1 = uVar13`，行 96/98——pending 存在

只消费 1 条 → 多事件时跨帧处理（行为差：原版一次画线、交付分多帧）。
→ FIX：改 `read().count()==0`/`read().last().is_none()`（全消费）。

### 3.2 FIX——signifier 记录（与 water §3.2 同源 core 契约疑误）

（perimeter 0x1411ff640 = BorderShape::perimeter ✓）；经 core 终结器

draw_water 的 0x20B 记录同形）→ stream.write（0x140b2cf90）。
交付经 core `UiAppendSignifier{tag:u8, Vec3, extra[12]}` 写入：
- perimeter 放 extra[0..4]=+0x14，机器码规范记录在 +0x1c（差 8B）；
- 缺 kind=1 @+8 字段；
- 名字串（0x142efa140 fat 区，同类 "…border…"）经 0x14089d8b0 进入写入流——
  core `UiSignifierStream::write` 签名缺名字参数；
- core 自身注释矛盾：write 自称"拷贝 0x28 B 记录"，而 UiAppendSignifier 0x20B、
  机器码最终记录 0x20B——core 侧重建不一致。
→ FIX（跨域，随 water §3.2 一并交 core 域 owner 裁决；crate 侧暂以字节对齐
本地落地或等待 core 修正）。
