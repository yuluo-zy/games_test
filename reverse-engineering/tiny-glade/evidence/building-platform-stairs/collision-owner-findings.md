# Platform stairs collision owner

The original module is `crates/country-core/src/systems/collision/world.rs`; A/B/C source checksums all differ. The precise source/function mapping is in `three-version-collision-owner-map.json`. These mappings establish ownership, not source-text or cross-version numerical equivalence. The numerical target remains original B RNE, not the patched Ghidra analysis image.

The platform caller builds one indexed collision mesh from accumulated eight-vertex cells and 36 indices per cell. Triangle chunks use std iterator/Vec mechanics. It requests an identity translation/quaternion and source tag7 with WallId at source+8, then uses the wall-keyed collider map. No accumulated vertices triggers the original remove consumer. The builder explicitly sets sensor=true; original subworld table maps tag7 to subworld7.

`RaycastMeshData::new_indexed` hashes triangle `[u32;3]` indices first and position float bits cast to `UVec3` second. Present optional float3 and float2 slices fold into the previous hash; None differs from Some(empty). Platform passes None for both options. `indexed_mesh_hash` delegates hashing to std `DefaultHasher`. `B-collision-hash-verification.json` executes the complete original prefix to 1408cef4e for 256 arbitrary-bit layouts and compares all fingerprints. It does not prove physical input reachability or rebuild a hash implementation.

A critical CFG discrepancy was caught by original instruction verification: patched Ghidra `Mesh::eq` C treats tag7 as a payload-free case. Original RNE jump-table entry `142aa44f4[7]` instead targets `1408cea79`, which compares WallId at source+8. The reconstructed policy compares fingerprint and WallId. No semantic conclusion uses the inaccurate switch grouping.

The original upsert keeps the prior collider handle only when `get_collider` returned a valid pose, all three translation and four quaternion floats compare equal, and complete tag7 mesh equality succeeds. Signed zero compares equal; NaN forces replacement. An invalid stored collider or mesh handle makes the original getters panic; the actual backend propagates an explicit invariant error instead of silently replacing. Absent map entry inserts. Replacement disposes the old collider and mesh instance before inserting the new mesh/collider and publishing the new handle. Empty output removes; absent remove is a no-op.

`B-collision-policy-verification.json` checks 512 resolved-owner contracts against actual original pose-gate instructions and complete original tag7 Mesh::eq: 47 Insert, 180 Keep, 285 Replace, zero differences. This is not a whole native RaycastWorld call: original map acquisition, `get_collider` state access, physics insertion/removal, dirty-tile rasterization and publisher infrastructure are separate integration boundaries.

The new `building/wall_platform_collision.rs` provides `PlatformStairColliderWorld<B>` for executable business ownership: real ordered cell→indexed mesh/fingerprint, map ownership by WallId, identity update, keep preserving the old handle, replacement executing backend remove then insert, and deletion cleanup. The backend trait requires actual sensor collider construction, subworld7 insertion/removal, old/new XZ AABB rasterization, subworld dirty marks and ordered ColliderDiff changes. A recording backend or CPU component alone cannot close this interface.

Original backend dependencies are locked Rapier 0.22.0 at PounceLight revision 7b5ece73c45a4d39bb983c48c283e773d7241050, Parry3D 0.17.0, and Slotmap B 1.0.6 (C changes to 1.1.1). Arc, HashMap, math, ColliderSet/SharedShape/SlotMap storage and spatial algorithms must be reused. No dependency algorithm is ported here. The parent owns Cargo and final Bevy backend wiring.

The original dependency-backed consumers additionally rasterize old/new collider AABBs, mark the corresponding physics subworld dirty, and publish ColliderDiff: Upsert discriminator0 through `Rapier::on_collider_upserted`, Removed discriminator1 through `dispose_collider_mesh_instance`. These side effects remain required for the actual World acceptance, alongside real physics queries and delete/no-output cleanup.

## Actual dependency backend

`building/wall_platform_rapier_backend.rs` now implements real locked Rapier ColliderSet and QueryPipeline storage plus Slotmap mesh ownership. It creates indexed sensor shapes in platform subworld7, stores the mesh key as collider user_data, retrieves actual poses, disposes old generation-bearing collider/mesh keys, marks the subworld dirty and performs real library ray queries. The original wake_up=false removal argument is proven at 1408d95ed. A required callback receives each old/new XZ AABB for the actual DirtyTiles owner; there is no default zero raster resource. ColliderDiff order and discriminator0/1 are preserved.

`B-rapier-backend-verification.json` checks 64 actual source-cell→complete original indexed mesh→original Parry vtable local-ray-query cases. Every mesh fingerprint and ray TOI matches bits. Each candidate sequence exercises actual insert/Keep/replace/new query/removal/miss/duplicate deletion; old slotmap and collider keys are invalidated, the diff order is0,1,0,1, and four real AABB callbacks occur. Queries reuse dependencies, not reconstructed intersection code.

This closes the executable isolated platform backend contract. Final Bevy wiring and real DirtyTiles cell rasterization remain parent-owned. The supplied callback in the scoped probe records actual AABBs, so it does not prove the original DirtyTiles grid/cell policy. Original all-subworld query filters and shared-world physics interaction remain explicit next-owner boundaries.
