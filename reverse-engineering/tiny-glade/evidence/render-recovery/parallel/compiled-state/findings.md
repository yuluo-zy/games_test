# Compiled graph / batch state findings

Target: workspace/input/tiny-glade.exe; SHA-256 f507a6cea25c5199447b88ba746a5293e64a279f73797ca74c1ce7f4ff2b7d03. Static evidence only. Original Rust source/ABI and runtime equivalence are not recovered.

## Observed

CompiledRenderGraph::new (0x1402c4280) initializes 0x218 bytes. Corrected layout: RenderGraph at compiled+0 (0x90 bytes); Vec<RecordedPass<PassResources>> at +0x90 (24-byte header, 64-byte elements); ResourceRegistry aggregate at +0xa8 (0x108 bytes); SynchronizationScope1 at +0x1b0 (80 bytes); Vec<u32> pending initial-transition resource indices at +0x200. ResourceInfo is registry+0x48, hence compiled+0xf0. Evidence: 0x140166510 calculate argument is registry+0x48, populate takes registry and graph, success calls new(graph,passes,registry). Constructor and record_batch corroborate consumers.

Constructor enumeration helper 0x1402bf880 scans registry lifetime records (24-byte stride, pointer registry+0x80, count +0x88) and collects indices whose first_access_index at record+0x10 differs from 0xffffffff. Record_batch clears pending Vec length at compiled+0x210 before consuming it. This is not a batch list.

BatchCompiler::new (0x140be95e0, objdump) writes Vec<Batch> capacity/pointer/length at 0/8/0x10, current start/end at +0x18/+0x20 and a bool at +0x28. Empty Vec pointer is 8. flush_batch (0x140be9600) does nothing if current start == supplied boundary. Otherwise it assigns end, takes/resets start/end and bool, pushes a 24-byte Batch, and sets start=boundary. Growth delegates to std Vec. It does not enforce monotonic boundaries.

Batch contains usize start at +0, usize end at +8, export-barriers flag at +0x10 (7 padding bytes unobserved). Executor evidence/render-architecture/0x1400fa190.c:164 constructs compiler; when executor flag at +0x188 & 1 is set it flushes for each pass index, otherwise it emits a whole-graph batch. It always flushes at total pass count and sets only last emitted Batch flag to 1. record_batch tests that byte before export barriers. The flag is not a queue selector.

add_pre_pass_barriers (0x1402c3d00) optimized first argument is registry, not compiled graph. Caller 0x1402c3240 at 0x1402c34b4 loads registry from recording context+0x10, established as compiled+0xa8 by record_batch. Registry access Vec fields are +0x48/+0x50/+0x58; pass access range Vec fields +0x60/+0x68/+0x70 (8-byte range elements). pass_access_range_indices (0x140be9690) returns its two u32 arguments as usize without transformation. ResourceAccessRecord stride20: resource +0, previous +4, next +8, synchronization group +0xc, access code +0x10. With no predecessor, skip when resource has no initial access state; otherwise transition code 0 to current. With predecessor, compare via can_be_concurrent_with (0x140bece70), skip concurrent accesses, else emit previous to current. Resource kind0=image, 1=buffer; aspect comes from format. Device/generation/kind mismatch and index failures panic. Physical barrier construction reuses raw rhapsody helpers; vk-sync classification is external.

record_batch (0x1402c1d40) requires an existing nonempty Vec<CommandBuffer> at argument6, stride0x58. It emits initial resource transitions into its last command buffer and resets shared scope. It validates batch start/end against RecordedPass count compiled+0xa0. It calls recording closure 0x1402c3240 or splits by PGO duration and joins parallel results. Returned CommandBuffers append to input Vec. It ends buffers from original last through penultimate, retaining final buffer for exports. Final flag triggers RenderGraph export records (pointer graph+0x20/count+0x28, stride48); barriers use last-access code if available, otherwise initial state, and target export access. CommandBufferSeqTracker tracks resource use. No queue submission occurs within record_batch.

Three compile monomorphs share calculate/populate/new success and populate-failure/on_retire/restore-state/drop-registry-and-passes/unavailable-result. Entry takes a 0x90-byte graph, marks first qword unavailable (0x8000000000000000), takes temporal state at state+0x90, executes closure, restores temporal state +0x90..0xef, then computes snapshot. Exact return enum and temporal map schema unknown. country-core pass/library/dynamic-constant work is inlined closure content, not generic compile source.

## Superseded interpretation

Early inspection reversed graph/registry blocks and mistook compiled+0x200 for batches. Both are superseded by compile tail arguments, calculate/populate pointer relations and record_batch consumers. An early stride0x58 label for RecordedPass is superseded: that stride belongs to CommandBuffer; RecordedPass is 0x40.

## Inferred reconstruction and unknowns

Candidate Rust recovers BatchCompiler flush/finish, pending resource enumeration and pre-pass transition decisions with an external concurrency callback. BatchCompiler new/flush passed 1600 exact original-entry Unicorn cases, including empty/nonempty range, bool reset, descending boundary and u64 boundaries; Vec capacity was preallocated and padding excluded. Report: native-batch-verification.json. The initial state projection requires validated initial access code 0 (the original asserts this before barrier construction). Generic snapshot owns graph/passes/registry and omits Vulkan calls. It is not a full compile or record_batch implementation. Registry ownership, vk-sync-fork provenance, full pass dispatch, queue submission, temporal schema and full graph/barrier native/runtime acceptance remain open. PDB void() records remain placeholder signatures. All candidate types are semantic projections, not a recovered repr/ABI.
