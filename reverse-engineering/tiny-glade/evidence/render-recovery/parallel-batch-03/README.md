# Rhapsody parallel recovery batch 03

Batch 03 closes three residual interfaces left explicit by batch 02:

- R5A projects compiled transitions and batches into barrier/record backend events.
- R5B traces command-buffer sequence ownership into the separate queue-timeline completion domain.
- R5C recovers typed temporal payload, replacement and reset behavior across frames.

`contract.json` is generated by `scripts/render-recovery/build_third_batch_contract.py`. The contract fixes entry points, interfaces, evidence boundaries and acceptance gates before integration. Each work package must label claims as observed, inferred or unknown.

This batch does not claim live Vulkan execution, GPU equivalence or complete original Rust ABI. Public dependency implementations remain outside the reconstruction boundary.

## Work packages

- `barrier-record/` and `reconstruction/render/work-packages/barrier-record-r5/`
- `sequence-domain/` and `reconstruction/render/work-packages/sequence-domain-r5/`
- `temporal-full/` and `reconstruction/render/work-packages/temporal-r5/`

## Result

- R5A passes 1,344 barrier native/Rust comparisons, 97 full population-entry fixtures, six R2 snapshot checks and four Rust tests.
- R5B separates command-buffer sequence from queue timeline, and separates command-buffer recycling from later in-order bucket drain. Two Rust tests and strict Clippy pass. The actual device counter constructor remains unexpanded.
- R5C restores raw texture/buffer tags, exported import, texture replacement rules, buffer reuse behavior and pair parity. Seven multi-frame CPU tests, formatting and strict Clippy pass.
- `python scripts/render-recovery/validate_third_batch_contract.py` produces `integration.json` with 13/13 cross-package checks passing.

The result is `consistent_partial`: full pass recording, live Vulkan/GPU execution, counter seed/global sequence uniqueness, temporal reset/drop and game pass integration remain open.
