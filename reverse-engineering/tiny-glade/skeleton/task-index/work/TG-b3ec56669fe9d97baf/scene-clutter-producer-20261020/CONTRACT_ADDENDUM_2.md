The frozen initial contract/addendum1 remain review inputs; the facts below refine their outstanding boundaries. They do not claim full instantiation or runtime verification.

* Addendum1's phrase “distinct paths with the same tree_stump registration name” was inaccurate. Both native tree_stump metadata calls use **the same path and registered name** `assets/meshes/tree_stump.json` / `tree_stump`; their actual metadata selector bytes differ (1 versus2). `loader-constant-call-arguments-B.json` is authoritative. The candidate already uses those exact same paths/names and correct different selector values; no code correction is needed for this prose error.
* Constructor order differs from blueprint argument order. Full cuboid is constructed at `0x1407e3d7b`; shrunken cuboid at `0x1407e3e21`. The first Arc allocation/copy at `0x1407e3ea1..3ec2` wraps **shrunken** geometry and stores its pointer at rbp+0x2e0. The second at `0x1407e3f4a..3f75` wraps **full** geometry. `set_colliders@0x1407e3fbf` receives rdx=shrunken and r8=full. Therefore the first/collision slot uses shrunken dimensions, the second/interaction slot uses full dimensions. Both use the same original-height local translation. 03's canonical physics design has been informed.
* Original blueprint mesh slots have three states: 0=positioned mesh; 1=explicitly absent; 2=unspecified. Fresh blueprint insertion sets unspecified. A missing required slot is an original failure, not equivalent to explicitly disabling a collider. Rust should preserve this semantic enum instead of conflating both states with Option::None.
* Overall blueprint equality is not supplied by deriving PartialEq on the builder. Native `instantiate_blueprints` checks unchanged Arc blueprint identity first. For different blueprint identities, it compares visual builder contents plus original output fields. Its mesh slots compare the **Arc allocation pointer**, ordered position components and ordered quaternion components: `0x14082862c..634` and `0x1408286d5..6e3` perform direct pointer compares before the float checks. Hash-equivalent geometry in a new Arc therefore still makes this visual differential branch changed. Canonical physics upsert separately compares mesh hash+source and may keep an unchanged collider; these are distinct consumer contracts. The accepted one-line builder PartialEq API only expresses its present semantic fields and does not stand in for this complete native comparison.
