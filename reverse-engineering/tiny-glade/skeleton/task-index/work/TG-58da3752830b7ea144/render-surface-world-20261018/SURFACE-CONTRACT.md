B-only evidence and candidate integration on the current Rhapsody architecture; the file family has C as index target, and no C semantic acceptance is asserted. Full native ranges/hashes are in native/manifest.json. Eight packaged shader files yield ten complete modules; all ten pass offline SPIR-V validation and translation. These are source evidence, not GPU execution evidence.

The recovered entry preserves refraction-copy, original seasonal water/ice selection and pre-TAA transparency. It uses the actual caller DrawLists and typed WorldLightingOutputs, true depth/half-depth/history/reprojection and the original process-byte control. No list, camera, geometry, GPU library, World or success gate is synthesized. The enclosing caller retains its existing single main FrameSetup and current session; no submission occurs inside the closure.

Native water/ice were one function with immutable World queries followed by mutable draw callbacks. Current owned phase carriers preserve the exact resources and ordering: prepare -> raster -> finish. Existing public entry points delegate to the same phases. The raster carrier only clones the existing trace Rc, not the compute environment. The production host uses three checked sequential RefCell trait views of the same existing PassEnv.frame; immutable WorldAccess is dropped before DrawPassCtx receives mutable World. It creates no second graph, allocator, table or shader cache and uses no unsafe alias.

The raster host validates resource kind against the current graph descriptor, projects all packet aliases before registration, keeps an active alias active, and uses the existing preserving/inactive graph access APIs. The native write/read code, group, actual descriptor and owner remain intact. Ordinary packets retain strict checks.
