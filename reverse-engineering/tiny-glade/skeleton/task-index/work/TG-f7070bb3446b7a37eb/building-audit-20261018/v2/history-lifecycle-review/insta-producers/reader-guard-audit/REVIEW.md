# Right-click input reader and resolved entity guards

Original B ui_convert at0x14099d6a1..d8ca executes EventReader::last: it consumes all unread primary/secondary events, selects the last unread event across both buckets, then resolves that single event's entity (payload qword at EventInstance+8 here). No unread event skips the helper. Invalid entity index, generation mismatch, missing dense mapping, mapping bound or unset component bit all skip handle_rmb_autoclutter. The original does not try an earlier valid click when the latest click fails.

The first draft of lifecycle owner's added producer forwarded every click before lookup. This would process intermediate clicks, permit invalid IDs to enter the helper and panic on a missing map record. Reported before freeze; owner agreed to fix latest-only forwarding with the existing complete-u64-key AutoClutterEntityIndex. Current parent-map adaptation is retained independently. RmbAutoClutterDirect contains a Record without an entity ID, so its mere presence cannot authenticate an arbitrary click. The legacy explicit RmbHit/direct entry remains separately available.

`native_right_click_reader_probe.py` executes the original last-reader/entity guards for14 cases: empty, multiple items, two buckets, old cursors, valid/invalid latest, generation/dense mapping/bit/bound failures. No business leaf is bridged; observation records the selected native ID and stops after all guards or at the skip exit, before component resolution. All selected IDs, reader cursor advances and guards match expectations. This closes last-selection/skip behavior, not the full mapping architecture or rmb algorithm.
