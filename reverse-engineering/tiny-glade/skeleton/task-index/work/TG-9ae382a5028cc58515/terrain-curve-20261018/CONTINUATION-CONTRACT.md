## Current-design implementation

PendingWallChanged owns existing typed `WallAuthoritySnapshot`s. It projects the previous first endpoint (extend-start) or last endpoint (extend-end) onto the next curve, clamps the resulting parameter, requires strict low<high, and preserves operation tag0/low/high bytes. The existing recovered utils projection supplies strict-distance/first-tie behavior; only representations are adapted, preserving authority points_u and length after construction. The deferred system drains once into one `WallCompoundHistoryEdit` group via the existing RecordWallHistory consumer and its shared transaction/error handling. It does not create an independent History or a duplicate wall store.

The false finish implementation accepts freehand source tags >=2 with snap<=1 and an actual previous snapshot. Valid continuation queues the exact state change, clears both continuation and active curve, and preserves live interpolated height. Invalid continuation removes live authority and records the original source/current color plus independent desired height for undo. False without a previous snapshot only clears progress and preserves the live row. Missing metadata, snapped topology and premade enclosure paths retain owners and diagnose their unresolved input.

Suppression reuses the current Modifiers, GameTime and CursorMovedScreenSpace owners. While active it adds delta and consumes all pending cursor events, measuring only the final payload. While inactive it leaves the reader untouched. Elapsed >=1 or accumulated distance >=50 clears flag and counters; the modifier check then re-arms the flag in the same frame without resetting counters. The old prose claiming per-event distance accumulation is withdrawn. Source tests cover inactive-reader retention, multiple pending motions, the last-only threshold and modifier re-arm ordering.
