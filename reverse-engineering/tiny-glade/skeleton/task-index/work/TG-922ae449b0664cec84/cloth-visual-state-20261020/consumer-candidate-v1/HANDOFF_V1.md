Main uses the exact ten original SystemParam kinds. Actual scoped main calls the now real absent-style clothline helper and consumes its Commands side effects.

Before/candidate/patch and exact dependency fingerprints are in CANDIDATE_MANIFEST_V1.json. Both candidate files parsed through rustfmt; this is not typecheck. Three wrong old generate-clothline tests of the removed manual flag route are replaced. None of these new/retained source tests has been run by this worker. No Cargo, rustc, GPU or production mutation was performed.

Tests use real same-World ClothInfo, Commands, canonical components and the same VisualState owner; actual clear_out_visual_entities exercises transient despawn on later invocations, and Local cache persists. Real Rapier geometry tests compare an occluder before and beyond the endpoint. Missing original normal texture is tested as an actual updater error, never a zero descriptor success. The CPU device fixture exists only inside tests, supplies real current library/buffer ownership contracts and rejects native upload/publication calls. It does not validate a GPU, texture loading, or whole-App construction. The already integrated shared math7-test result is separate and does not validate this consumer.

Remaining boundaries: upstream two window Box<ClothInfo> producer paths, original schedule ordering/caller installation before Nani44, actual named installed beam/normal label mapping and asset loader execution, transient/unload whole-App reachability, complete styled/general flag branch, C parity and GPU execution.
