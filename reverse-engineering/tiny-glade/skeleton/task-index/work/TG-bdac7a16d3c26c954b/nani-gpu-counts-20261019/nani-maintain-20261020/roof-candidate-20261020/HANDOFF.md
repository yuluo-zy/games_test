## Implemented gates and value flow

* Actual descriptor-bearing kind9 entities, including existing keys, need a real canonical Roof, Transform, StoneFloor marker and exactly one mapped marker. Preflight occurs before removal/new allocation/changed-mesh processing, preserving the current fail-before-key/count policy. Floor-only or missing inputs remain explicit errors; an empty registered library is not rejected.
* The new updater preserves the original With<InstanceDataMarker<StoneFloorInstanceData>> domain. Its data Query contains canonical mutable key, Transform, **Option<&Roof>**, Option<&RoofAnimation>, and no descriptor requirement. An active key+marker+Transform with no descriptor and no Roof enters the updater and gets a specific unsupported error. Required &Roof, With<Roof>, or With<NaniInstanceDesc> would silently filter this row and are not used.
* For a real Roof, safe reads project the existing88B owner to22 existing numeric words. Animation comes from `values()[0]`; absence retains the already recovered original1.0 branch. Roof wins over the original optional Floor branch, so passing no Floor for this restricted Roof-present path supplies no invented game data.
* The existing `circle_tangent_u0` function now projects the actual four circle words to the current shared `::utils::geometry::circle::Circle2d` and calls its real u=0 tangent. The old zero-vector placeholder and obsolete “Circle2d is a stub” statement are removed. No parallel circle helper/type is introduced. Original NaN/remainder behavior remains delegated to the same shared implementation.
* One actual kind9 subset lock is taken before iteration, including an empty query, matching the original failure order. Payload/position/radius/dirty range updates reuse the existing typed subset and dense-key hint mechanism. A missing Roof errors before mutating that row's key hint or payload. This is not a transaction across all query rows; preceding valid rows may already have updated, as with native per-row failure.
* The new unordered update is placed at original tuple index5's relative position between window and plant updates. Existing maintain→explicit ApplyDeferred→updates→one flush remains unchanged. VAO prefix ownership and roof business registration remain separate. As in the original updater, a missing/non-owned RoofFloor subset fails even for an empty query; no resource-exists bypass is added.

All19 existing public numerical `build_*` bodies and all20 legacy row-view plus nine existing ECS update bodies were independently compared and remain unchanged. Only the authorized circle helper, input/preflight tuple, one new ECS updater, registration entry, explanatory docs and focused tests change. `STATIC_CHECKS.json` records the comparisons.
