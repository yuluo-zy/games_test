# Actual roof merge selector, distinct failure and rank payload

Owned task TG-4f402 was approved and normally claimed as part of the calculate closure. This source design covers original142000e60/2592B (PDB3063:264) and its first-proposal closure141fe6a40/1247B (PDB3053:264), from the same B/PDB f507a6ce/2d9686b8. The complete main body inlines the same proposal for later candidates; both paths must agree. No source or execution acceptance is implied by collection.

The original output is a u32 destination-tagged value: failure writes tag4, successful roof proposal tag0. Its logical successful fields are yaw, Vec2 roof coordinates, resulting rank, target ID and distance. It is **not** the wall proposal's byte+5f==2 option. Original success writes through+6c (0x70B extent), while current source's0x34B comment and invented blocked state are wrong. Rust should return Option<RoofMergePosition> with destination:canonical RoofDecoratorDst, target_id:DecoratorId, resulting_rank:u8, distance:f32. Do not mirror padding or manufacture a storage owner/edge flag in the output.

The real inputs are actual Info, candidate roof coordinate, actual input world position, actual Roof, same-owner candidate ID slice and Decorators bucket, canonical DerivedDecoratorInfoView. Input world position is passed to roof section shape lookup on each accepted candidate. No caller-supplied guessed rectangle, closest-edge point, new_along_width or old independent mesh/subtype pair may replace these actual resources. The original main parent first computes a real collision-hit list using its actual cache and original roof overlap callback; it then calls this selector on that list. That original overlap remains the collision task's separate required dependency, not an invented overlap check inside this selector.

For each candidate, in order:

1. Require ID in actual bucket; missing target panics, not skip. Resolve its actual subtype through View and require exact existing-rank collision key **before** family/rank tests. Require selected destination through the actual roof accessor at its original later point, rather than treating every bucket entry as roof on entry.
2. Family is `(ty-38)u8<8 ? ty-38 :6`, shared with wall merge. Only family6 also requires exact type equality. Rank addition widens to usize, compares actual input type's max rank, then narrows accepted sum. Do not wrap u8 or clamp3f to6.
3. Require actual existing subtype + **merged rank** collision. Delta=(mergedWidth-existingWidth)*.5; this is not new-input-rank width minus old width. Every lookup stays on the same canonical real mesh owner, and absent exact key is required failure.
4. Call actual Roof shape-from-position-clamped using the genuine input Vec3. For rectangle enclosure, use its genuine rectangle, actual closest edge at input world XZ, and `(delta/edge_length)*.25`. For circle, divide delta by actual section perimeter. Shape lookup, rectangle dispatch and geometry utility failures stay visible; no default shape or inferred precomputed local point.
5. Required target roof destination supplies existing U,Y,yaw. If existingU<candidateU, proposedU=existingU+delta; otherwise (including unordered) proposedU=existingU-delta. Existing Y and yaw remain. This is the opposite of current source's sign. There is no subsequent projection/clamp of proposed U in original.
6. Distance=sqrt(dy*dy+dx*dx), dx=proposedU-candidateU and dy=existingY-candidateY, in original f32 order. Original Info state is copied in the unused payload but does **not** become the option sentinel. Thus state2 does not itself block a roof proposal as it does wall selection.

Take the first accepted candidate with no eager finite comparison. Later accepted proposals compare ordered f32 distances; unordered panics, strict smaller replaces, equal keeps first. Return None if all candidates fail family/rank or input target list is empty. Missing bucket belongs to parent option handling, not a default fabricated bucket. Parent copies canonical roof payload, selected target and resulting rank into accepted intent, and preserves its independent original input rank.
