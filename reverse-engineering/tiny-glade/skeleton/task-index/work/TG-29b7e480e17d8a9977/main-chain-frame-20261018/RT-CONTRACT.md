# B RT upload and binding contract

Scope: canonical GPU upload element identities, storage owners, publication counts, compute/draw binding. Original B only. Source build adapters do not claim the original object ABI or restore the asynchronous BVH builder.

RNE SHA256 f507a6cea25c5199447b88ba746a5293e64a279f73797ca74c1ce7f4ff2b7d03. `rt-rne-manifest.json` binds complete PDB procedure sizes (3287/4167/4970 bytes), rather than truncated first Ghidra bodies. `rt-binding-original.json` and constructors-original in the RT claim retain read-only database results.

1. `AssetSsboLibrary::add_new<RtTrianglesSsbo>@1412c3550` allocates **48 bytes**, writes count0 at +0 and copies the actual 40-byte buffer at +8. Same construction for Meta and BVH. These are InstanceBuffer storage, not zero-size carriers and not bare TypedStorageBuffer.
2. Canonical names: RtTrianglesSsbo / RtTriangleMetaSsbo / RtBvhSsbo under `resources::rt`. Slot NAME strings are RtTriangles / RtTriangleMeta / RtBvh; original SsboId keys match their xxh3 hashes. WallColorIdSsbo is the already-real `resources::color_id` producer, slot WallColorIds; no second carrier.
3. Element sizes 24 / 4 / 80; native fixed capacities 0x40000 / 0x40000 / 0x10000. Three constructors allocate 0x600000 / 0x100000 / 0x500000 bytes, usage0x22, memory1, alignment4. None supplies no upload data; do not zero-fill these buffers as a substitute producer. Typed-slice native constructors validate capacity with len <= BUFFER_LEN. The byte/InstanceBuffer adapter additionally validates element multiple and alignment; do not attribute those checks to the typed-slice body.
4. `upload_rt_world@1408bd2db` takes an **Option** pending tuple, sets it to None using the Vec-capacity niche. `1408bd319/320` skips None. An explicit Some(empty) sets all three counts0 without writing GPU bytes. No pending work preserves prior counts/data.
5. Successful uploads run triangles, meta, BVH in this order. Each checks actual buffer byte capacity, uploads nonempty bytes, then **always sets instance_count=len**. Count is not a buffer ID.
6. Whole-input bounds are strict: (tri_len | meta_len)<0x40000, bvh_len<0x10000. The out-of-range branch logs the original error and stderr lengths, drops pending data and returns; it does not panic. Capacity/backend failures still unwrap/panic. Original global log-dedup macro is a separate diagnostic dependency.
7. `bind_ray_tracing<ComputePass>@1415fc230` gets actual typed InstanceBuffer for triangles/BVH before resource accesses, then reads triangles/meta/BVH/wall in order. Uniform hashes1c9f2eef0ac739ac and c2b7f2fdf5e21521 receive **low u32 of instance_count**, subject to the existing shader-field lookup and offset bounds checks. `bind_ray_tracing<DrawBuilder>@1416289d0` reads the same count owner, with draw slot cache and access0x1f.
8. Producer `init_populate_ssbo_library@140909e80` registers the three RT entries. Its full set contains other real SSBO owners; restoring three entries does not complete that full startup function. The scene FramePasses and BVH worker remain separate integration gaps.
