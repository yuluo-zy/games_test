# Original finish recording input-sync event

Original B control_input_replay 0x140941a30 reads 48-byte EventInstance entries. At 0x140941bd3 the overflow test identifies the first-qword niche 0x8000000000000000 and takes the sync branch. At 0x140941c5e it loads a byte from event+8 into R8D; 0x140941c6d calls the matching-PDB-identified InputStream::on_history_sync at 0x1409494c0 with that byte. This is an actual consumer binding, not an inference from Rust variant ordering.

on_history_sync tests R8B at 0x1409494e0. Zero first clears both retained queues and their logical positions before pushing the new sync point. Nonzero keeps the retained queues, applies its observed old-point retention policy when needed, then pushes the new sync point. Therefore the finish_input_recording producer's first-qword niche and +8=1 map to the current existing InputReplayCommand::Sync { record: true }. No raw native event layout or second event type is required. Current input-stream retention is a separately hand-refactored algorithm; this schema finding does not replace it or claim full original control-function parity.

Original DecoratorStorage::mark_mutable at 0x140a1c2b0 is called directly by system_decorator::restore_archived_decorators at 0x140817a9f. The call is unconditional before that system's event/mode guards. The current systems/decorator/src/restore_archived_decorators.rs already calls storage.mark_mutable(), but the inspected current host/core registration contains no call to that complete system. Binding history_finish_recording's original mark_immutable without restoring the corresponding next-frame writable phase would block later edits. The restored full system has additional collision/archive requirements and should not be registered blindly just to run its first line.

sync-native-manifest.json and sync-native-pack retain four identity-bound original ranges and six matching-PDB symbolization samples: the actual control consumer, on_history_sync, restore entry and mark_mutable leaf. These are bounded byte/source evidence, not a new native fixture or a claim about the complete original schedule. Only read-only analysis was performed; no producer or shared registration source was changed here.
