# Terrain canvas argument/layer correction, original B

This minimal correction is incremental on the currently integrated terrain UI. The earlier frozen versions remain unchanged. It fixes four constants and adds one actual UI regression covering four caller branches. The old claim that R8 held the argument was wrong: it held the Rust string length. No shared UI source, native container, new module or scheduler is introduced.

Original B caller 0x140a9feca..ff07 supplies the 17-byte terrain_deny_draw name in RDX/R8, argument0 in R9 and layer1 at caller stack+0x20. The draw call 0x140a9ff0c..ff49 supplies the 12-byte terrain_draw name, argument3 in R9 and layer2 at caller stack+0x20. Original constructor 0x14092df72 saves R9B, 0x14092e007 loads entry stack+0x28 (the caller's stack+0x20), 0x14092e0bd writes the saved argument at WidgetParams+0x79, and 0x14092e0ca writes the layer at +0x89. The current API already has these two distinct fields; only the call-site constants were misread.

The existing WaterRaster gate remains: deny is registered for a positive water sample and either absent cursor or distance<=0.5; draw is always registered. The original caller's unordered water comparison skips deny. Five original caller executions independently capture both real call ports, including wet/dry, absent cursor, near/far and NaN water. Four original constructor executions confirm argument/layer remain distinct, plus extent130, occlude0 and record_history1. String formatting/hash, the nested UI registry and bilinear sampling are supplied dependency boundaries; caller gates and constructor field writes execute original instructions. The identity-bound original raw ranges and matching PDB samples are retained in native-pack. Neither function boundary nor full UI dependency implementation is claimed by these bounded ranges.

Native constructor record_history1 corresponds to current no_history_recording=false. That is a separate necessary shared UiState correction owned by history/root; this patch intentionally does not edit it. Root must integrate that shared correction for the lifecycle chain. This candidate's regression checks the actual ui_draw_terrain system creates draw(argument3,layer2) and conditional deny(argument0,layer1), using literal original expected ports so it catches accidental reuse of the string lengths.

This worker performed no Cargo invocation or production edit. Root owns compilation and integration. No C parity, complete global scheduling or GPU/runtime acceptance is asserted.
