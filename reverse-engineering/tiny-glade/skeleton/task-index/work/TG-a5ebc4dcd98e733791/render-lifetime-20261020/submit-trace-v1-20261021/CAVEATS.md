# Timer V1 观测边界

禁用热路径指 OnceLock 完成初始化之后：只读取缓存 bool/Option，不取 Instant、不遍历观测元数据、不分配。首次初始化读取环境变量时，若存在变量，std::env::var_os 的 OsString 可能分配；不宣称首次调用绝对零分配。

启用诊断在原函数 scope 退出时向 stderr 写一行。为保原锁生命周期，输出可能仍处在既有锁覆盖范围内，因而会延长诊断运行的持锁时间。真实 driver mark 在输出之前取样；顶层总耗时可含内层诊断输出开销。本探针用于定位约 13 秒的数量级来源，不替代未启用探针的正式性能基准。禁止用该结果宣称业务或长稳已完成。
