# Existing AudioLoop monotonic-clock adapter, target B

Scope authorized by root: preserve the user's hand-refactored AudioLoop fields, ring/start/stop algorithms, stop(now: Duration), and deterministic existing tests. Add stop_now() to supply a live monotonic Duration and mechanically change real audio consumers currently passing constant zero. No production/Cargo source edits from this task; root applies integration hunks to shared consumers.

Observed original B: RNE SHA256 f507a6cea25c5199447b88ba746a5293e64a279f73797ca74c1ce7f4ff2b7d03; PDB SHA256 2d9686b8eaaf5c672c8dbc3aed85fbfeaf2a98a0dc64353191cd1a123a5d8911. Stop 0x140a59430 first calls std::time::Instant::now at 0x140d635e0, retains it, and on later calls invokes Instant::elapsed at 0x140d63910 before testing the threshold. Exact raw-byte extraction and PDB dependency identities are retained in evidence/. No C address was queried. B/C file source checksum equality is a reuse candidate, not C runtime acceptance. Claim metadata defaults C; this contract explicitly follows root's current B core target.

Current producer/consumer mismatch: current stop(now) measures elapsed time from its first supplied Duration; each live consumer passes Duration::ZERO, so the elapsed value never becomes positive and the loop never reaches its stop backend/ring advance. A process-local std::sync::OnceLock<std::time::Instant> origin and its elapsed Duration provide one monotonic domain without new fields, resources, dependencies, or duplicate state. stop_now() delegates to the exact current stop(now). It is independent of paused/replayed GameClock, like the original Instant timer.

The current stop(now) uses full Duration and preserves time reversal saturation, Result retry, and existing flags. These are intentionally retained current design behaviors. Original B rounds elapsed to milliseconds before its threshold comparison; this adapter does not claim byte-equivalent threshold arithmetic, reconstruct the original layout, or roll back current API. It fixes the live clock wiring only.

At candidate creation, 19 exact constant-zero call sites in 14 production audio sources use AudioLoop. The integration-owner patch changes only those call expressions to stop_now(). Existing explicit-time tests and all other audio algorithms remain unchanged. Source hashes and replacement counts are in manifest.json. Root retains shared ownership and resolves concurrent changes by patch context rather than whole-file replacement.

One added regression starts the current loop, requests stop through the live adapter, waits 2ms with zero configured delay, then requests again and observes the real stop/cursor/reset effects. Existing deterministic stop(now) tests remain the precise threshold, wrap, error, and timing contract. No Cargo build/test is run here; root owns unified verification. This is current-architecture compatibility repair, not full audio/game/C acceptance.
