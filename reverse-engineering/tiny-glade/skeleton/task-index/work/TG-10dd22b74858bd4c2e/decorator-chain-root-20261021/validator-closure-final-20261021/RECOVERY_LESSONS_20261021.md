# 本轮原证驱动恢复经验

1. 不依赖同名函数概括判别副作用：TG69原8936先写specific，898c..89a1某些类型回到8600继续；既有“所有overlap拒绝”的笔记不准确。把PC→继续/拒绝出口与写入时刻逐条锁定，先修合同再实现。
2. 同方法名不能当相同泛型特化：tuple140b26a80是external*local，另一140b26d20是local*external。保同一SharedShape Arc，以已证IsoTransform.nested_in合成，仅适配当前consumer；不改其它专化、不复制碰撞世界。
3. shared canonical owner优先：Locator显式addr+actualId，Storage direct lookup与d2s lookup是不同函数；四表、typed subtype、真实mesh Arc、prepared/arch高度均required。不能按名字扫桶、造bbox、用ZERO补未就绪producer。
4. 反馈不是空UI记录：需沿真正SignifierFactory→共享builder→mesh/shader组件→动画/TransientMesh owner。duration0的初始scale仍ZERO，真实动画消费者后续扩至value；不能因截图前一帧不可见而绕过动画。
5. 夹具必须满足原几何合同：二维三角形仍是合法convex；短高度表/长path的相邻采样原也panic。负例应锁真实失败前提，不能改生产几何或容差让错误夹具通过。
6. 冻结源码保持不可改：rustfmt stdout多文件首行包含文件名，不能回写Rust。parse-only只声称解析，不声称编译；当前before逐字核对后用窄patch，保并行root的新imports/actualID。
7. 跨ISA arithmetic NaN sign与有限值算法分开：只对原499B中已定位两case的算术NaN符号遵循本地Rust官方合同，保quiet/payload/lower31bits与其它全部bit，x86仍32bit；不推广为任意NaN容差。
8. 测试数字不是完成度：本闭包选定50项待验证源码测试，净新增39，且独审、CPU、真GPU、生产mount是不同事实。完整函数可调用也不能替代原set25前后flush、cache/derive、编辑历史和卸载前提。
