# Cottage side-cap actual64B return contract (bounded design)

This is the complete1362B B callback1412905d0 and its two real callsites within the complete10926B14128db20 Cottage tile assembler. It is not an emitter. The call ABI's RCX is the caller's64B return slot, RDX is the real capture, R8/R9 are endpoint references and the first stack argument is the side boolean. Parent14128f80b and14128fadb call it, copy all64B to the actual emission record, then push atf852/fb22. The capture has height references at0/8, an unused UiSignifierStream reference at10, the same pinned RNG at18 and the same Roof reference at20. No new renderer, buffer owner, allocation or registry is introduced.

The natural safe private helper will return the existing country_core::resources::roof_tile_ssbo::RoofTileSsbo. Its semantic inputs are the two current row cap heights, endpoints from/to, side flag, shared fastrand::Rng and same Roof. This is a source API adaptation, not a claim that a Rust capture has native ABI. It belongs in the already claimed Cottage assembler source, not a new independently registered system. It must integrate with the full assembler's actual edge branches; exposing an unused helper alone cannot complete the business chain.

The operation order is fixed by the entire original body:

1. Load both captured heights. Rust-min semantics are explicit: if first is NaN use second; otherwise MINSS(second,first), preserving operand selection/ties. Add exact-.1 (bitsbdcccccd) to form bottom. Read to.y/to.x/to.z, then from.x/from.z and from.y. XZ center=(fromXZ+toXZ)*.5; centerY=(to.y*.5)+(bottom*.5), in that order.
2. Let dx=to.x-from.x, dz=to.z-from.z. Dimensions=(sqrt(dz*dz+dx*dx),to.y-bottom,.1). Lift(dx,dz) to the real (dx,+0,dz)3D direction. Raw normalize separately using sqrt(dz²+(0²+dx²)), no finite test/fallback/renormalization. Let D be that direction, Y=(0,1,0), N=D cross Y. Keep the actual zero multiplications/subtractions when expressing the original basis; do not replace all components by mathematical signed-zero constants.
3. Quaternion is from the original basis columns(D,Y,N). For side=true, position=center-N*.08 and quaternion unchanged. For side=false, position=center+N*.08 and quaternion multiplied by the exact nativeYpi=(0,1,0,f32bitsb33bbd2e), not a hand-written W=0 quaternion. Offset .08 uses bits3da3d70a in all three original lanes. Native quaternion multiplication/order must be preserved with the pinned canonical math implementation, not normalized afterward.
4. Clipping plane normal is (to-from) cross N, unnormalized. W is sign-bit flip of (to.z*normal.z + (to.y*normal.y + to.x*normal.x)); do not replace it by a normalized plane or derive it from the shifted tile center.
5. Pack quaternion to4half at9be; pack the four plane values to4half at9e4; pack dimensions to3half at9f1, writing an explicit zero fourth u16. Then draw exactly one i32 in -100..100 from the same RNG. Rejection sampling belongs to the existing pinned fastrand implementation, no manual RNG clone/reseed. Only after this draw read the same Roof's low32 identity.
6. Return all64B of the canonical record: position, current_height=+0, packed clipping plane, packed3dims/zerohalf, packed quaternion, real Roof low32 id, velocity_rotation=0,animation_t=1, seed, is_circle=0,is_main_roof_body=0. All fields are actual output; Default must not silently fill an uncertain field.

Actual edge and failure/side-effect boundaries: parent emits the ordinary body first, then first-column trim and this cap with false if the real flag is enabled, then independently last-column trim and this cap with true if enabled. Both edge checks run for a single column interval. The flag never disables the trim itself. Each canonical SparseInstanceBufferWriter push result NoFreeChunks is ignored by the original callers, so a failed insertion does not stop later RNG/geometry. This does not turn allocation failure into successful GPU completion: actual writer/owner accounting stays canonical. No capacity pre-check/continue may suppress the original callback's RNG advancement.
