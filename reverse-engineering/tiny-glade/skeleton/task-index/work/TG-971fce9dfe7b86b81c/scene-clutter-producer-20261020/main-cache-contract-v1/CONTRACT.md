# Dormer main real two-pass cache design (geometry integration remains gated)

This bounded design covers the real Local<CacheDormerPositions> history/diff portion of complete14207B generate_dormer_roofs1407cb1a0 and its actual551B insert/330B remove helpers. Native bodies are complete, every instruction and contiguous span were rechecked directly against original B. Cache state is CPU history only, not another decorator registry or GPU owner. It must be introduced in the already owned assembler source and consumed by the real ten-parameter system; an unused class or empty main cannot be reported as a completed geometry chain.

Actual current shared system signature is DerivedDecoratorInfoResources, Res<DecoratorStorage>, Res<DecoratorBlueprints>, Res<CachedDecoratorTransforms>, Res<PublicWalls>, Query<&Roof>, same AssetSsboLibrary (safe host port ResMut), Res<UiSignifierStream>, ResMut<DormerTiles>, Local<CacheDormerPositions>. The first two native profiling scopes use actual puffin; preserve real scope hooks, not fixed false booleans. No Commands, transient visual owner or mutation of Blueprint values belongs here. In particular current placeholder overwriting BP with emptyBlueprint is wrong and must be removed by the final implementation.

A cache value projects exactly: full64WallId, cached.translation Vec3, Roof.floor_y f32, Roof color u32, same Roof.parameters raw28B value. Use the existing canonical RoofParameterBlock to carry those28 bytes. It is a known semantic projection over the actual authority, not a new guessed ABI. Cache map is std::HashMap<DecoratorId,Snapshot> with original empty default; no Clone/Default snapshot with dummy values, no GPU allocation handle in snapshot. Snapshot equality is custom native mixed ordered equality; do not derive byteEq or compare the authority's raw full Roof88.

First pass creates a new map using real RandomState and scans ALL live Storage wall maps and ALL their current infos, not iter_modified, not an invented placed state==2. For each id, canonical Derived view.try_get_subtype(id) returnsOption; None skips. Eligible subtypes are {1,2,7,8,23}, plus subtype0 only if info.rank==3 (bay). This is an actual branch exception, not a default subtype. Find PublicWalls.roof_entity(wall), then actual Query<&Roof> entry; missing identity/query entry skips. Only then required CachedDecoratorTransforms::transform(id) is called (missing cache panics). Read translation, Roof parameters/floor/color and insert the snapshot under actual DecoratorId. Source rank/subtype/rotation/scale are not extra cached equality fields: do not add them just because they seem useful. Current real subtype owner is DerivedDecoratorInfoView, never legacy get(id).subtype()/bbox records.

After new-map construction, compare each current entry with old Local map. If id is absent, append currentWall to the dirty Vec. If same id has a different fullWallId, append currentWall FIRST then oldWall. If wall is equal, compare in the exact short-circuit order below; any mismatch appends only currentWall:

1 translation.x, then.y, then.z;
2 roof parameters profile float@8, height float@12, tipX@0, tipY@4, ridgeLength@16;
3 ridgeDir byte@24;
4 eaveLength float@20;
5 flatRim byte@25;
6 floor f32;
7 color u32.

Each float is ordered == (native UCOMISS unequal OR unordered branches). NaN is never equal even to itself; +0==-0. Parameter padding26/27 is ignored. Do not compute later payload projections before translation differences: keep lazy && placement. Key wall equality comes before all floats. Projection storage is original entry64B{DecoratorId@0,WallId@8,translation@16,floor@28,color@32,params@36}; this documents native evidence only and does not require repr(C) for the Rust snapshot. Native comparisons are atbc007..bccef, and order above is bound to exact offsets, not guessed struct declaration order.

Every matching current id is removed from the old map after the add/equal/mismatch handling. Remaining old entries append their oldWall, covering removals, becoming ineligible, missing Derived values/roof/query entries, or moving outside authoritative current Storage. Dirty IDs are sorted/deduplicated by fullWallId. There is no per-ID emit attempt, all dirty walls are rebuilt once. Replace the old Local cache with the full new map BEFORE looking up the optional RoofTileSsbo storage. Do not roll cache back if the buffer is absent or geometry later fails; do not add a retry generation flag absent from native. This is a meaningful original failure behavior, not a claim that an absent startup buffer is acceptable in the full application.

Only after this cache/diff phase does actual dirty-wall geometry begin. Empty dirty Vec performs no mutable SSBO/resource access. For nonempty dirty walls, actual missing AssetSsboLibrary key optionally skips after cache advancement; if key exists but storage has a wrong runtime type, original downcast must panic rather than be confused with missing. Current safe API supports preserving that distinction with contains<RoofTileSsbo>() followed by get_mut<RoofTileSsbo>().expect(...), using same actual owner. Full type-name assertion remains the shared library's check. Do not change AssetSsboLibrary or manufacture a temporary storage.

Existing canonical DormerTiles.allocations owns full64WallId→actual SparseAllocation<RoofTileSsbo>. Dirty wall resolves actualRoof again, obtains/creates that same roof.wall_id allocation, obtains actual writer (current tail or normal last free chunk) and calls clear BEFORE sequential geometry. Missing wall-decorators may leave a cleared allocation as original. No replace_all/atomic rollback, no capacity guard skipping later RNG, no fake writable marker. Native551/330 CPU HashMap helpers and standard library replace/take/drop are reused semantically; no authored hash-table implementation is needed. Deletion remains the already integrated separate actual DeleteRoofCmd EventReader consumer, not a new cache eraser.

The actual branch geometry/producer integration is still a hard independent design gate: BP is only contains(id), then required Derived subtype and native bay/Cottage/Gothic branches. Seven48B BP hole records are not read here. Existing final48B upload/real fullvisual recurring outputs and actual RoofTile allocation are two separate branches. No cached equal entry is permission to bypass another system's recurring side outputs or copy_previous. Nested generate→maintain and original middle scheduling/flush semantics remain from the independently reviewed phase contract; no new schedule installation in this package.

Meaningful required tests (all UNRUN) must call the actual snapshot/diff implementation used by main: ordered NaN and ±0/padding cases, each comparison field including both bytes, full64WallId movement with dirty old+new, cache hit/no dirty, new/remove/ineligible/missingDerived/missingRoof transitions, and post-cache optional-buffer skip without rollback. A sameWorld real system fixture must read current Storage/Derived/PublicWalls/Roof/CachedTransform and actual Sparse owner; no mirror cache algorithm or manually successful buffer token. Actual geometry tests and fullApp/copy/flush/GPU remain separate until all dependencies compile and their real consumers run.
