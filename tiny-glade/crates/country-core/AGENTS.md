# 保留手工重构成果，增量恢复业务

2026-10-18 用户明确要求，适用于本 crate 及其功能依赖：

- 其他功能模块已有用户手工重构。涉及这些模块时，以当前代码和模块结构为起点，添加缺失功能、修复 bug；不要照原版重新复现整个模块，不另造一套重复实现，不覆盖已有重构成果。
- 这不要求保留过于简单或错误的算法。若当前手写算法比原版业务简单、无法承载已经挖出的逻辑，应直接在现有模块中重构该算法并补齐业务，复用已有可用部分。
- 原版二进制用于核实业务规则、边界与副作用，不要求复制原生内存布局或恢复旧工程架构。优先沿用当前类型和接口；确有必要调整时连同现有消费者一起修复，避免留下并行的新旧实现。
- 原版业务证据、当前工程改进、局部验证和完整游戏验收分别记录；不要将手工重构回退为旧候选，也不要把局部通过称作整个模块完成。
