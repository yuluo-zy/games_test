本轮覆盖 `src/` 全部生产模块，进行源码审查、实现维护和 Rust 测试；未调用逆向工具。保持公开模块路径和有效序列化格式。用户授权纠正原先逆向补全时保留或推测出来的错误行为，因此这里的“修复”不表示与原二进制在这些错误边界上等价。

## 第二轮复审后的修复

上一轮的 131 项通过记录未覆盖以下缺陷；本次为每项保留最小回归，并新增 26 项聚合复杂测试。历史报告仅证明对应源码版本。

| 缺陷 | 当前处理 |
| --- | --- |
| 对 `[0,1]` 重复减空半开 `[0,0)`，12 次生成 4096 段 | 空半开区间直接返回；接触/覆盖/孤立点分支明确区分，不产生重复零宽碎片；重复裁剪稳定。 |
| 三角形共享顶点的结果随顶点绕序变化 | 用 f64 相对坐标计算平面截线，再求截线区间重叠；固定大小候选数组，无堆分配。共面判定结合单位法线夹角及各自最长边的相对距离容差；非共面截段按舍入误差界判定，不按长边吞掉短交段。移除细长比退化阈值，只拒绝零面积；交线端点顺序不保证。 |
| 矩形重合、共边或共角时 slab 平行分支产生 0/0 并漏报 | f64 局部闭边界 slab 检查，单独处理平行面；逆变换直接除轴长平方，避免倒数乘法缩小旋转轮廓；保留“轮廓接触”的接口语义，严格包含不算轮廓相交。 |
| 墙坐标在首尾重复点外推时归一化零方向，得到 NaN | `CurveSampling` 增加带默认实现的端点方向方法；`Curve2` 扫描首尾非零段，全退化时保持端点。 |
| `extend_left(0)` 中 `(t-1)+1` 抹掉很小的 t | 零距离严格恒等；正距离直接在局部 t 上计算，避免无必要的相消。 |
| 极大有限周期坐标的相减吞掉相位，距离甚至超过半周期 | 普通范围保留快速路径；多圈、溢出、次正规周期和半周期临界值使用 f64 各自求余后再归约，半周期方向仍取负。 |
| 从极大未归一化坐标插值，短位移被舍入消失 | 周期插值在 f64 中先规约位移乘积再与起点相位合并，覆盖大参数外推和次正规周期；墙坐标周期分支复用该实现。 |
| 极短非零段平方下溢被当零段，极长段平方溢出；切片扩展跨错段 | 向量长度增加稳定后备路径，正常量级保留原运算；切片距离和扩展计算使用 f64，有限端点差可超过 f32 上限。公开长度仍为 f32，不能表示的曲线总长仍拒绝。 |
| RDP 跳过靠近起点的左子链，并用无限直线距离，省略点误差可超过 epsilon | 处理所有子链，使用 f64 有限线段平方距离；端点间距降为软偏好。准备省略的点另用 TwoSum 与 FMA 残差计算距离上界，修复巨大端点吞掉细小偏离量的问题，不确定时保守保留。原输入 fixture 保留，已知错误输出改由独立递归参考及逐点误差合同检查。 |

历史三角形数据中的绝对体积阈值分类不再作为当前正确性的标准，304 组输入继续运行并与独立边-三角形参考比较；线段结果按无序端点比较。切片历史测试仅对正距离运算调整舍入容差，零距离仍严格相等。本次没有删除或忽略测试组来绕过失败。

## 结构与性能

- 将大段历史样例从 `camera`、`natural_cubic`、`rdp`、数值工具等生产文件移至测试模块。原主要数值样例继续运行，没有通过ignore整组历史数值测试来掩盖失败；冗余构造断言由独立矩阵不变量覆盖。内部变量按点、段、系数、长度、窗口等业务含义命名。
- 模块和API注释解释输入要求、错误、边界及性能原因；历史地址/反编译过程不再充斥主要实现。仍未确认语义的 `CameraLens.field_*` 不凭猜测改成误导性业务名称。
- `IndexCondenser::insert` 使用HashMap Entry，去除一次重复哈希/查找；句柄命中仍直接比较缓存位置，无哈希查找。
- 区间裁剪在两个Vec间交换复用，避免每次重新分配。独立计数分配器探针对实际源码测量：两次预热后，对固定两段结果进行20,000次重复裁剪，alloc/realloc均为0；不据此推断所有裁剪输入零分配。
- 本地时间偏移从RwLock换为单个AtomicI32 relaxed读写，没有附带状态同步。5,000,000次单线程读取微基准，归档的三轮测量中旧锁约161.9–185.8ms，原子读约7.16–16.64ms（后台同时进行Release编译）。只测读取内核，结果受机器负载影响，不代表稳定提速比例、完整日期格式化或游戏性能。
- 矩形最近边比较使用平方距离，减少四次sqrt；曲线近似投影保留sqrt，避免未经必要裁决改变浮点近似tie选择。
- 样条复用已计算的节点；分段采样先计算容量，再一次申请输出。
- 正确性有成本：失败原子性的原地平滑使用候选点集；备份使用sync_all；AABB平行分支及数据校验增加边界开销。没有以“高性能”为理由省略必要校验。

## 保留边界

- `Curve.points/points_u/length`、样条系数和部分几何字段仍公开；直接写入可破坏不变量。本轮未进行破坏性的全包API封装。
- 曲线最近段和UV三角查询仍为线性扫描，RDP最坏为二次时间；本轮未引入空间索引；RDP 已改为具有有限线段误差界的实现。若实际负载包含大量重复查询，仍需基于该负载测量后选择索引。
- 公共采样点数上限受f32表示能力限制，不是整个应用的内存配额；接收任意外部模型时调用方仍应定义资源预算。
- `rotation_from_normal` 对非单位输入不保证单位四元数；退化重心坐标保留IEEE结果；Coplanar只表示同平面。
