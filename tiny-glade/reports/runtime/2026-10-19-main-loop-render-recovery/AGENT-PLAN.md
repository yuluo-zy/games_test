# 八个智能体的任务与验收

用户最新要求总共8个：中央root+7个执行者；禁止继续分叉。此前多余agent已中断或因额度错误停止，其历史记录保留，不再唤醒。

|执行者|具体责任|关键交付|
|---|---|---|
|中央root|同步、接口裁决、共享源码整合、串行构建/GPU、进度与经验|实际可运行结果和受影响回归|
|1 主循环|OS/update/worker handoff/错误/退出|主循环完整生命周期候选|
|2 主图|compile_main全部分支、UI/菜单/截图、export/present|完整主图consumer接线|
|3 世界图|真实W1–54输入/状态、渲染错误分类|非空连续世界帧候选|
|4 启动场景|缺失模块、资产/VAO/Forest/Nani、None音频、重载|真实场景producer和生命周期|
|5 水冰折射|真实水/冰/折射、ripple/RT/history|两主题多帧GPU用例候选|
|6 底层与性能|保留重构架构、同步/缓存/内存/descriptor、热点测量|有证窄修与同输入性能对比|
|7 独立验收|原证复核、完整WSI、source漂移、经验沉淀|独立findings和实际接受边界|

所有完整启动提示词在 agent-prompts/：每份均含目标、当前输入、独占写面、跨任务接口、禁止事项和验收要求；COMMON.md统一规定只在合法claim写候选、root单点生产整合与执行。roster.json是本轮角色配置。不要将角色配置当作全部worker已成功运行；实际启动/额度失败另记。
