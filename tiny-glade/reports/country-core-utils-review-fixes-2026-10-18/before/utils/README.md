# 游戏侧工具模块

本目录服务编辑、世界栅格、资产加载、调试绘制和音频。通用数学与容器复用 glam、Serde、Bevy、标准库及 [共享 utils](../../../utils/README.md)，不再按反汇编逐条表达业务。

2026-10-18 重构以功能正确性为准，允许修正逆向解释。变更和验证见 [REVIEW.md](REVIEW.md) 与 [重构报告](../../../../reports/country-core-utils-refactor-2026-10-18/README.md)。旧原版差分报告不覆盖本次行为变更。

## 栅格更新

世界 XZ 范围为 `[-65,65]`，映射到 64×64 瓦片；每瓦片对应 8×8 个栅格像素。位图每行一个 u64，总大小 512 字节。

- 矩形参数为 `[min_x,min_z,max_x,max_z]`，转换结果采用半开区间 `minimum..end`，上界允许为 64。完整世界矩形覆盖全部 4096 格。
- 矩形置位和相交查询使用整行位掩码，最多处理 64 个机器字，无临时堆分配。
- 非有限、逆序或完全落在世界外的矩形不标记边缘；单点查询对非法输入返回 None。
- 连续笔画至少需要两个点，半径必须有限且非负。先限制输出范围，每段最多访问 4096 格，不枚举网格外格子。
- 保守覆盖使用半径的轴对齐外扩，允许多标记少量边界格，保证圆头笔画不会漏标。负坐标用 floor。
- 可能触及世界、且端点或半径超过 16 个世界宽度时，保守标记全图，避免浮点精度丢掉原点偏移；完全位于世界外的范围仍直接跳过。
- `extend` 和发布增量按位 OR；`take_and_clear` 取出快照并清空当前位图；`retain` 按行、列递增筛选已置位格。

通用 `conservative_plot_line` 的输出量仍取决于实际跨度。固定网格必须使用 `conservative_plot_line_in_bounds`，先裁剪整数输出范围，再生成格子。

## 网格加载与热重载

```json
{
  "indices": {"buffer": [0]},
  "attributes": ["Vertex_Position"],
  "Vertex_Position": {"type": ["float", 3], "buffer": [[0, 0, 0]]}
}
```

向量直接反序列化为 glam 类型，不经过中间数组再转换。成功发布需要：

- 必须有非空 `Vertex_Position: float3`。
- 法线为 float3，UV 为 float2，颜色为 float3/float4；其他自定义属性可用 int1 或 float1/2/3/4。
- 类型描述必须恰好两项，属性名不重复，所有顶点属性长度相同。
- 浮点数据有限，索引不越界；空索引允许。

`try_load_json_as_mesh` 对文件、语法和校验错误全部返回带上下文的 Err。资产库只在成功后替换旧网格及登记修改，坏文件不会污染正在使用的资产。启动时不可缺少的资产可用 `load_json_as_mesh` 将错误提升为 panic。

## 坐标与编辑几何

像素原点在左上，比例屏幕空间原点在屏幕中心，上方为正 Y。窗口宽高最小按 1 像素处理。投影统一使用 glam 齐次矩阵乘法，保持第一个矩阵产生的 w。

`try_world_space_to_screen_space` 和 `try_project_onto_ray` 返回 Option，显式处理不可投影点。兼容的点投屏入口返回 NaN 坐标；射线投影入口失败时保持起点。range 限制屏幕插值参数，随后按裁剪 w 转成世界参数；非法 range 在便捷入口报错，在 try 入口返回 None。

子墙保留区间方向，切片校验插值结果属于 `[0,1]`。闭合曲线重接先检查分割与闭合前提，过短或无效结果返回 None，复用切片结果的 Vec。折线网格的空点集属于调用错误。

## 调试折线

`DebugLine::try_show` 校验点、线宽和逐点颜色后提交工厂；`show` 对无效输入告警并跳过。名字使用标准哈希，包含实际颜色、UI 通道和虚线模式，避免错误去重。

唤醒时查找已注册 shader，将类型化 Mesh 放入现有资产库，创建带网格/shader/Transform、绘制拓扑及瞬态回收凭据的实体。虚线参数为总长×4，UI 请求带 UiPass；普通请求进入世界绘制路径。shader 缺失时不创建空壳实体，实体销毁后复用瞬态资产维护系统回收网格。

球和三维矩形继续提供请求构造器，本轮没有添加它们的绘制 API；其他调用方使用的原生布局构建器仍有恢复边界。CPU 实体链通过不等于真实 GPU 画面验收。

## 状态与依赖约定

- 采样使用共享 CENTERED_PATH：旧模式保留旧存档边界外推，新模式按格心采样。`load_game_session` 取得有效存档后按 `version >= 0x1a` 应用开关；准备阶段/仅回放命令不改策略。完整 World 读档写回仍由加载模块负责。
- 索引压缩委托共享实现。删除交换末项，消费方须同步交换并行数组；提示允许过期。ID 不含 generation，删除后重用的生命周期由调用方负责。
- 音频首次 stop 记时，严格超过延时后停止；播放请求取消计时。Duration 比较不回绕，后端失败不推进 cursor，构造拒绝空队列。公开字段为兼容已有调用保留；建议使用 current/current_mut 并维持队列有效。
- Transform 默认单位缩放，forward 为旋转后的本地 -Z；保留字段序，数学复用现有实现。
- Resource 可变访问返回 Bevy Mut。事件 drain/last 清空整个流；独立订阅者应使用 EventReader。
